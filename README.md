# Sun-and-Moon-Pixel-Art-Game
A Unity 2D pixel art game featuring Sun and Moon themes, creative gameplay mechanics, pixel art visuals, animations, and interactive game environments. Developed with Unity and C#.

Sun and Moon move together on one keyboard. Sun uses A, D, and W. Moon uses the arrow keys. Each chapter asks them to hold a crossing, gather keepsakes, and reach home at the same time.

Verified changes are recorded in [CHANGELOG.md](CHANGELOG.md).
